已配置的服务

    勾选左侧圆点即为当前使用的服务。API Key 只保存在本机浏览器 (chrome.storage.local)，不会同步或上传。

    从左侧选择一个服务，或点击「+ 添加」新建。

    选择后会自动填好接口地址与默认模型，之后仍可手动修改。

    可直接输入任意模型名，下拉里的只是建议。点「拉取列表」向该服务查询当前真实可用的模型。

    留空表示不发送

    Claude Opus 5 / Opus 4.8 等模型已移除 temperature，传入会返回 400，因此 Anthropic 接口不发送该参数。

    附加请求头（可选）

    JSON 对象。OpenRouter 等服务可能需要额外的来源标识头。

    快捷键

    默认 Alt+A 翻译 / 还原整页，Alt+S 翻译选中文本。

    自动翻译的站点

    每行一个域名，支持 *.example.com 通配。打开这些站点会自动整页翻译。

    从不翻译的站点

    优先级高于自动翻译列表。

    性能与请求

    字符

    每批都要重发一遍系统提示词，批次越小提示词占比越高（6 段/批约 61%，16 段/批约 37%）； 批次越大首段出现得越晚。两个上限同时生效，调一个记得看另一个。

    译文按段落缓存 7 天，跨浏览器重启有效；翻错了的段落可在此清掉重译。
